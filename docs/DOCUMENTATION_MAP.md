## Classification policy

| Status | Meaning |
|---|---|
| CURRENT | Matches the scoped present contract/workflow; not proof of runtime/production acceptance |
| HISTORICAL | Original execution, fixture, review or planning stage retained with its date and scope |
| SUPERSEDED | Specific original clauses are explicitly replaced by later source/contracts; frozen historical results remain valid historical evidence |
| NEEDS_REVIEW | Mixed stale claims, missing authority or unresolved contradictions; preserve rather than invent a decision |

This map covers every 349 originally tracked docs file at dev 6601f62, plus the separately archived root README. Classification uses inspected content, current code/contracts and independent authority review, not filename/date alone. `reference*` is a provenance location, not an automatic obsolete label. The [machine-readable map](audits/evidence/docs_reorganization/PATH_MAP.json) supplies per-file purpose/type/status reason, current reference, inbound/outbound links, hashes and conflict IDs. Machine-readable/frozen payloads retain original bytes. Old paths inside manifests identify their recorded execution; use this map without rewriting those records.
