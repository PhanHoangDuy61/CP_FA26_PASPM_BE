# Historical Documentation Archive

HISTORICAL preserves a dated stage; SUPERSEDED identifies an explicitly replaced rule. NEEDS_REVIEW means authority remains unresolved, not deleted. Full per-file classification is in [DOCUMENTATION_MAP](../DOCUMENTATION_MAP.md#classification-policy).

Product/Category/CI are already integrated in the baseline described by the [architecture index](../architecture/README.md).

Original feature specifications remain discoverable beside their [feature indexes](../features/README.md) under `reference*`; not every old requirement is discarded simply because its folder moved. Dated audits/testing reports remain in their domain directories with classification notices. No original artifact is deleted or deduplicated.
