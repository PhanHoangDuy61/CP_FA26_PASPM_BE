GET
/api/mining/runs/{id}/patterns
Page raw high-utility patterns by utility descending, canonical Product IDs ascending

Empty while pending/failed; check run status. Utility is frozen weighted utility, not revenue. pageSize controls display only and never changes minUtil. Support is not measured.
