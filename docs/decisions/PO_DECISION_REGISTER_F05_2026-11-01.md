## Rules until decided
- No schedule can be enabled through the API (503), and the dispatcher does not start unless an instance sets `paspm.mining.schedule-dispatch-enabled=true`.
- The five System Admin read routes are **disabled by default** (HTTP 403 even for System Admin) and are enabled only by an operator setting `paspm.mining.system-store-read-enabled=true` for integration testing; they are not released to end users. Approving D1 means changing that default through a reviewed change, not merely editing this document.
- Approved decisions must be recorded here with date and approver, then reflected in `F05_MINING_API.md` and `OPTION_B_BACKEND_API_HANDOFF.md`.
