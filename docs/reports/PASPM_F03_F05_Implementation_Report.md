## Worker lease integration continuation — 2026-10-31

- `MiningWorker` no longer performs global startup recovery. Each JVM creates an owner UUID, polls eligible persisted requests every second, claims a 30-second lease before work and renews every five seconds. Queue rejection preserves the PENDING row. An expired owned request is eligible for reclaim; a legacy RUNNING request with no owner is deliberately left untouched. Committed requests preserve their original Store, frozen input, snapshot and configuration.
